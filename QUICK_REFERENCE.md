## 🎯 Design System

### Colors
- Primary Gradient: `violet-600 → purple-600 → indigo-600`
- Logo Gradient: `violet-300 → purple-300 → pink-300`
- Glow: `violet-500/50` to `violet-400/70`
- Glass: `backdrop-blur-32px` with `rgba(255, 255, 255, 0.15)`

### Typography
- Logo: `font-black` (900), `tracking-wider` (0.08em)
- Main Tagline: `font-semibold`, `text-white`, `tracking-wide`
- Subtext: `text-white/70`, `tracking-tight`

### Spacing
- Button Padding: `px-10 py-5` (primary), `px-12 py-6` (final)
- Gap Between: `gap-6`
- Button Border Radius: `rounded-2xl`

### Animations
- Spring Easing: `stiffness: 400, damping: 20`
- Hover Scale: `1.03` (normal), `1.04` (final CTA)
- Hover Y: `-2px` (normal), `-3px` (final CTA)
- Click Scale: `0.98`
